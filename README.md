# Prom proposal

One page, no build step. Open `index.html` in a browser, or host this folder with GitHub Pages.

## Before you share it

Put `girlfriend.jpg` and `vine-boom.mp3` in this folder, next to `index.html`. The page still works if either file is missing.

## GitHub Pages

1. Create a new GitHub repository and upload `index.html`, `girlfriend.jpg`, `vine-boom.mp3`, and this README.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.
5. Wait a minute. The site will be at `https://<username>.github.io/<repository>/`.
